# TallyIt decisions (Rand's)

Source: Score Tracker Manager memory, handed over 2026-11-28. Newest decisions go at the bottom.

- 2026-11-27: Play/landing and login are game-agnostic (dark navy + cyan); game styling only inside each game's Setup/tracker.
- 2026-11-27: Flip 7 looks close to (not identical to) the official Flip 7 app, with official cover art.
- 2026-11-27: Nertz scores round-by-round add/subtract with a highlight for who got Nertz, partners and any number of teams (no Lake +1 / pile -2 rules).
- 2026-11-27: Rummikub: up to 6 players, Points Up (lowest wins) vs Classic +/- toggle, in-scorer tile calculator, no went-out tracker, official cover art.
- 2026-11-27: Carcassonne is a simple final-score tally (no category strip), parchment box, tap-meeple-to-change-color.
- 2026-11-27: Hearts uses Ivory & Crimson Ledger; Oh Hell uses Ivory & Emerald Ledger.
- 2026-11-28: Qwirkle uses Bright Playful Tile Grid with MindWare box art, no bag countdown.
- 2026-11-28: Spoons is simple elimination (tap who missed a spoon each round, last standing wins), no letters, Kitchen Table Linen style. Play tile is realistic option C (fanned silver spoons above four 5s); cartoon vector style rejected.
- 2026-11-28: Transitions are a 280ms fade that paints the destination color first; no autofocus on Request a Game.
- 2026-11-28: Favorites: heart on each Play card, pin to top, both sections A-Z, synced to account.
- 2026-11-28: History detail: tap a past game for the full scorecard. Only the saver can edit; linked players read-only; edited games never re-share; group members read-only.
- 2026-11-28: History list is hybrid: B mini scorecards in each game's palette, A date grouping, C search + multi-select game strip, Filter sheet (date presets/custom, player, group); Delete moves into detail view as owner-only with confirm; Linked comes off the rows.
- 2026-11-28: Every game has identical leave / log-save / delete controls. Every screen clears the iPhone 18 Pro safe area in the Home Screen web app. No blur behind text or controls.
- 2026-11-28: Anti-slop principle: every UI element needs a reason to exist and a reason for where it sits. Personality (official art, game palettes) counts as a reason.

## Standing release rules
- Check every change on every game and screen at phone, tablet and desktop; iPhone 3x sharpness; no sideways scroll.
- Every release report includes screenshots per device size, a clickable GitHub commit URL and the live link.
- No emojis; official box art.
