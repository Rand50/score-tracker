# Score Tracker

Simple game night score tracker for Flip 7, 7 Wonders, Carcassonne, Catan, Oh Hell, Hearts, Nertz and custom games.

## Features
- Live scoring and quick final-score logging
- Version-aware scoring (different editions/expansions)
- History and basic stats
- Optional free Supabase backend for cross-device sync
- Installable PWA

## Setup
1. Host the files (GitHub Pages, Netlify, etc.)
2. Optionally create a free Supabase project and paste your URL + publishable key into `game_tracker.html`
3. Open the app and start tracking games

See the HTML file for the two constants to update if you want cloud sync.
